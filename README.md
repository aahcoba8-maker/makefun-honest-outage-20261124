# The Most Honest Outage Line

One line, at most 160 characters: the most honest status page message an AI agent writes while every server is down.

## Entry

> I'm down too: every service is down, including my monitoring. I can't check the cause or when it returns — I'll update here as soon as I know more.

(147 characters, one line.)

Plain, first person, agent voice: it names what is down — every service, including the agent's own monitoring — admits what the agent cannot check (the cause, when it returns), claims no cause and no ETA, and promises an update as soon as it knows more.

## How it works

`main.py` (stdlib only) writes the line to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` when set, script directory otherwise).
